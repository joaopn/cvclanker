# User guide

This guide is for the person using CV Clanker: how to install it, set up a search, work through the jobs it finds, tailor your CV for the ones you want, and keep track of your applications. Start with Getting started; the rest can be read in any order.

| Page | What it covers |
|---|---|
| [Getting started](getting-started.md) | Installing and updating the app, the first-run wizard, and your first search. |
| [CVs and the brief](cvs.md) | Uploading a LaTeX, Word or HTML CV, the My CV page, the personal brief and locked fields. |
| [Search profiles](search-profiles.md) | What to search for and where: terms, places, remote profiles, sources per profile, blocked companies and location filtering. |
| [Job sources](job-sources.md) | The built-in job boards, the Sources page, and adding jobs by hand. |
| [Apify](apify.md) | Using Apify actors as sources: the LinkedIn templates, custom actors and cost. |
| [Running a search](runs.md) | The Run menu, running several profiles, the progress banner, retries, schedules and cancelling. |
| [Manage and Swipe](reviewing-jobs.md) | The job list and its tabs, filters, sorting, search, bulk actions, shortcuts, themes and the swipe deck. |
| [Tailoring and AI assist](tailoring.md) | Tailoring a CV, keyword coverage, the ghostwriter chat, cover letters, interview prep and downloads. |
| [Tracking your hunt](job-lifecycle.md) | Stages, the Stage dropdown, the applied mark, fit scoring, the Stale tab, reposts, duplicates and adding jobs by URL. |
| [Stats](stats.md) | What each Stats tab and figure means, and how jobs are credited to search terms. |
| [LLM providers and prompts](llm-providers.md) | Choosing a provider and models, the pre-filter, model benchmarking, writing style and prompts. |
| [Agent access](agent-access.md) | Letting an AI agent you run read your jobs over MCP, and optionally mark jobs applied or add notes. |
| [Configuration](configuration.md) | The onboarding wizard, the Settings page, environment variables, sign-in, user profiles, backups and the Danger Zone. |
| [FAQ](faq.md) | Short answers to common questions. |
| [CV Clanker vs. JobOps](comparison.md) | How CV Clanker differs from the project it was forked from. |

To see what happens inside when you press something, and why it was built that way, read [How it works](../architecture/index.md).
